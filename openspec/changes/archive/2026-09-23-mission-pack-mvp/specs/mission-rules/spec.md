# Spec Delta

## Purpose

ミッションパックの有限バッグとクリア条件（累計ライン消去）および勝敗判定を定義し、クラシック無限サバイバルと区別する振る舞い契約を提供する。

## ADDED Requirements

### Requirement: ミッション定義の基本パラメータ
システムは、最初のミッションについて盤面幅10・高さ20、目標タイプ `clearLines`、`goalLines` が4、バッグ周回数1（標準テトロミノ7種を各1回含む有限バッグ）を MUST で適用する。ホールド機能は MUST NOT で提供する（提供禁止）。

#### Scenario: 最初のミッションの固定パラメータ
- **WHEN** プレイヤーが最初のミッションを開始する
- **THEN** 盤面は10×20であり、クリア目標は累計4ライン消去であり、使用可能なピースは標準7種を各1回ずつ含むバッグ1周分に限られる

#### Scenario: ホールド不可
- **WHEN** プレイ中にホールド操作を行おうとする
- **THEN** システムはホールドを提供せず、現在ピースの退避は行われない

### Requirement: 有限バッグの消費と枯渇
システムはミッション開始時に標準7種をシャッフルしたバッグを1つ用意し、スポーンごとに1つ消費することを MUST とする。バッグが空の状態で次ピースが必要な場合、未クリアであれば失敗として扱うことを MUST とする。

#### Scenario: バッグ枯渇で未クリアなら失敗
- **WHEN** バッグ内の全ピースを使い切り、かつ累計消去ライン数が4未満である
- **THEN** システムはミッション失敗とする

### Requirement: クリア条件は累計ライン消去のみ
システムは、ロック後のライン消去により累計消去ライン数が `goalLines`（最初のミッションでは4）以上になった時点でミッションクリアとすることを MUST とする。他の目標タイプ（高さ制限・時間サバイバル等）を MVP で要求することは MUST NOT とする。

#### Scenario: 4ライン到達で即クリア
- **WHEN** ピースがロックされライン消去が行われた結果、累計消去ライン数が4以上になる
- **THEN** システムは直ちにミッションクリアとする（バッグに残りがあってもよい）

#### Scenario: 未達では継続
- **WHEN** 累計消去ライン数が4未満であり、バッグに未使用ピースが残っている
- **THEN** システムはプレイを継続する

### Requirement: スポーン不能は失敗
システムは、次ピースをスポーン位置に配置できない場合、ミッション失敗とすることを MUST とする。

#### Scenario: 天井アウトで失敗
- **WHEN** 次ピースのスポーンセルが既存ブロックと衝突する
- **THEN** システムはミッション失敗とする

### Requirement: 軽めの初期ゴミ
システムは、空盤ではなく軽めの初期ゴミ（下寄り・穴あきを含む固定パターン）を持つ盤面でミッションを開始することを MUST とする。具体セル座標の一意性は実装で定義してよいが、開始時点で少なくとも1つ以上の固定ブロックが存在することを MUST とする。

#### Scenario: 開始時にゴミがある
- **WHEN** ミッションを開始する
- **THEN** 盤面にはプレイヤーが置いていない初期固定ブロックが1セル以上存在する
